# BIT-RoboDragon (北京理工大学屠龙智能车挑战赛)

## 项目概述

BIT-RoboDragon是为北京理工大学屠龙智能车挑战赛开发的Arduino智能小车控制系统。该项目实现了多种功能模式，包括蓝牙遥控、红外循迹和超声波避障等，使智能小车能够适应不同的比赛环境和任务要求。

## 硬件要求

### 主控板

- Arduino UNO开发板

### 传感器

- 红外循迹传感器 (4个)
- 超声波测距传感器 (3个)
- 蓝牙模块 (HC-05/HC-06)

### 执行器

- L298N电机驱动模块
- 直流电机 (2个)
- 舵机 (tulong版本)
- 发射机构 (bth_v2版本)

### 其他组件

- 电池及电源管理
- 小车底盘及车轮
- 连接线缆

## 功能说明

### 1. 蓝牙遥控模式

通过蓝牙连接，使用手机APP发送指令控制小车的移动方向和速度。

**控制指令：**

- 'F': 前进
- 'B': 后退
- 'L': 左转
- 'R': 右转
- 'S': 停止
- 'A': 发射 (bth_v2版本)
- 'E': 舵机控制 (tulong版本)
- 'C': 退出红外循迹模式
- 'D': 退出超声波避障模式 (tulong版本)

### 2. 红外循迹模式

使用四个红外传感器检测地面上的黑线，实现自动循迹功能。系统根据不同的传感器组合状态调整小车的行进方向，确保小车能够沿着预定路线行驶。

### 3. 超声波避障模式

使用三个超声波传感器检测周围环境中的障碍物，实现自动避障功能。系统根据不同方向上障碍物的距离，调整小车的行进方向，避免碰撞。

## 代码结构

项目包含两个主要的Arduino程序：

### 1. bth_v2.ino

基础版本的智能小车控制程序，包含蓝牙控制、红外循迹和超声波避障功能，以及发射机构控制。

### 2. tulong.ino

改进版本的智能小车控制程序，在基础功能上增加了舵机控制，并对部分参数和逻辑进行了优化。

## 使用方法

1. **硬件连接**

   - 按照引脚定义连接各个传感器和执行器
   - 确保电源连接正确，避免电压不匹配
2. **程序烧录**

   - 使用Arduino IDE或VS Code+Arduino插件
   - 选择正确的开发板型号(Arduino UNO)
   - 选择正确的串口
   - 烧录对应的程序(bth_v2.ino或tulong.ino)
3. **操作说明**

   - 启动小车后，默认进入红外循迹模式
   - 通过蓝牙发送'C'指令可退出红外循迹模式，进入超声波避障模式
   - 通过蓝牙发送'D'指令(tulong版本)可退出超声波避障模式，进入蓝牙遥控模式
   - 在蓝牙遥控模式下，可以使用各种控制指令操作小车

## 引脚定义

### 电机控制

- a1 (2): 左轮正传
- a2 (3): 左轮反转
- b1 (4): 右轮正转
- b2 (5): 右轮反转
- leftPWM (10/6): 左轮PWM控制
- rightPWM (11): 右轮PWM控制

### 红外传感器

- L_SENSE (7): 左侧红外传感器
- R_SENSE (8): 右侧红外传感器
- L_SENSE1 (6/12): 最左侧红外传感器
- R_SENSE1 (9/13): 最右侧红外传感器

### 超声波传感器

- TRIG1 (A2): 左侧超声波触发引脚
- ECHO1 (A3): 左侧超声波回响引脚
- TRIG2 (A4): 中间超声波触发引脚
- ECHO2 (A5): 中间超声波回响引脚
- TRIG3 (A0): 右侧超声波触发引脚
- ECHO3 (A1): 右侧超声波回响引脚

### 其他

- shoot (12/10): 发射机构控制/舵机控制

## 调试技巧

1. 使用Serial监视器查看传感器数据和运行状态
2. 调整PWM值可以改变电机速度，从而调整小车的运动性能
3. 修改超声波避障的阈值可以调整避障灵敏度
4. 根据实际循迹线路调整红外传感器的判断逻辑
